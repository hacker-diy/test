# MC / Magic Control Android WebView

Universal Android wrapper for Magic Control devices.

- App name: MC
- Brand text: Magic Control
- Device URL: http://192.168.4.1/
- Package: com.magiccontrol.mc
- WebView file chooser enabled for Lock Screen wallpaper upload.

## GitHub Actions build

Open the repository Actions tab and run `Build MC APK`, or push changes under `mc-android/`.

The debug APK is uploaded as an artifact named `MC_Magic_Control_debug_APK`.
